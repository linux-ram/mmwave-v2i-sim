# IEEE paper build (v0.1 partial)

v0.1 ships committed figures under `paper/figures/` and LaTeX source in `paper/main.tex`.
Automated PDF builds in CI are tracked in GitHub issue **#3** (m9).

## Prerequisites

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Optional for PDF output:

- `pdflatex` (TeX Live or MacTeX)

## One-command build

From the repository root:

```bash
bash scripts/build_paper.sh
```

This runs, in order:

1. `python scripts/generate_validation_report.py` — writes `artifacts/validation/validation_report.json`
2. `python scripts/generate_paper_figures.py` — regenerates `paper/figures/fig_density_sweep.{pdf,png}` from the report
3. `pdflatex` in `paper/` (twice) when `pdflatex` is on `PATH`; otherwise figures and `main.tex` remain ready

## Figures only

```bash
python scripts/generate_validation_report.py
python scripts/generate_paper_figures.py
```

The density-sweep figure uses the **sim_engine** block in the validation report; the dashed reference line (when present) comes from the legacy comparison proxy.

## Output artifacts

| Path | Description |
|------|-------------|
| `paper/figures/fig_density_sweep.pdf` | Committed figure (regenerated by script) |
| `paper/figures/fig_density_sweep.png` | PNG variant for slides/README |
| `paper/main.pdf` | Built locally with `pdflatex`, or download from the **Paper PDF** GitHub Actions workflow artifact |

## Reproducibility notes

- Fixed seeds in validation and batch sweeps yield deterministic JSON.
- CI does not require `pdflatex`; committed PDF/PNG figures satisfy v0.1 release gates.
